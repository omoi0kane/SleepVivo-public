# リリースノート

## v0.3.0

- 「睡眠ログ」で、今回の記録や分析結果を確認し、最近の記録を比較できます。
- 起床後の任意の3問に、概要や睡眠ログ、VR Overlay から答えられます。集計中も回答を保存できます。
- 一般設定で、音声分析に使うマイクと起動時の自動開始を設定できます。結果は睡眠ログに表示されます。
- 概要から次の就寝・起床時刻を変更できます。起床だけの設定にも対応しました。
- 「概要」「睡眠ログ」「設定」などの画面を見直しました。

導入と更新は[インストール](../user-guide/installation.md)、研究への参加は[同意と参加](../research-program/consent.md)をご覧ください。

## 以前のバージョン



### 0.2.5 Pre-Alpha (2026/9/28)

* 任意参加の Research Program で、観測セッションの要約が送信できない場合がある問題を修正

### 0.2.4 Pre-Alpha

* SteamVR と同時に起動した際、VR オーバーレイに `127.0.0.1` の 404 エラーが表示される問題を修正。オーバーレイの画面ファイルの読み込み経路を改善しました（[issue #1](https://github.com/omoi0kane/SleepVivo-public/issues/1)）。
* アプリ内に「調査用ログ提出」を追加。問題が起きた日付とログの種類を選んで提出できます。提出には Research Program への参加が必要です。

### 0.2.3 Pre-Alpha (2026/5/2)

* SteamVR終了時にSleepVivoが自動終了する設定をデフォルトに
* 睡眠ログの記録形式を拡張
* オーバーレイ表示404エラーに関するupstream由来のマイナーバグを修正(完全に治ったかは不明)

* 「まだ寝ない」時の復帰トランジションを10秒へ短縮
* 起床サポート中に中断・復帰した場合、明度・色温度が復帰しないバグを修正
