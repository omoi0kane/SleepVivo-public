# Polarを基準にした初期評価方針

SleepVivoでは、睡眠・覚醒の推定と起床支援を改善するため、Polarの睡眠記録を基準にした評価を進めます。

このページは初期開発の評価方針です。以下の評価手順や改善が、配布中のアプリですべて実装済みであることを意味しません。

## まず比較の基準を作る

初期開発では、Polarが判定した睡眠・覚醒を評価上の正解ラベルとして採用します。そのラベルとSleepVivoの推定がどの程度一致するかを測り、改善前の基準値であるbaselineを作ります。

別の測定手段が得られるまで開発を止めるのではなく、まず同じ基準で比較できる状態を作ります。将来、基準を補正したり別の測定結果と比較したりする場合にも、元の記録と旧版の結果を残します。

## 改善前後を同じ条件で比較する

現行の結果をB0として残し、修正版をB1以降として比較します。記録の品質や時刻の扱いに未解決の点がある場合は、暫定結果として条件を明示します。

睡眠・覚醒それぞれの一致だけでなく、判定できた時間の割合、判定できなかった理由も確認します。難しい区間を除外しただけの変化と、推定そのものの改善を区別するためです。

## 睡眠状態と起床の希望を分ける

一時的に覚醒していても、そのまま休息を続けたい場合があります。睡眠状態の推定と、その瞬間に起床支援が適切だったかは別に評価します。

Polarは睡眠状態の比較に使います。一方、本人が起床支援を取り消した操作などは、支援が意図に合っていたかを評価するために使います。本人の操作でPolarの元の睡眠ラベルを書き換えることはしません。

## この評価で示すもの

この段階で示すのは、採用したPolarラベルとの一致と、起床支援の動作の違いです。医学的な診断精度や、SleepVivoによって睡眠自体が改善する効果を保証するものではありません。

実際の明るさや音量を変えずに候補の判断だけを比較する評価も予定しています。その比較だけで、睡眠への効果を結論づけることはしません。

## データと参加について

初期検証は、開発者本人が提供した既存の記録を対象に進めます。この方針の掲載によって、利用者のPolarデータや詳細な観測記録が新たに自動収集されることはありません。個人の生記録や識別情報を公開文書へ掲載することもありません。

Research Programへの参加は任意です。収集される情報、同意、参加の停止や撤回については、[収集される情報](../research-program/collected-data.md)、[同意と参加](../research-program/consent.md)、[プライバシー](../research-program/privacy.md)を確認してください。
