# SleepVivo

SleepVivo は、VR で眠るときの入眠と起床を支援する Windows アプリです。このマニュアルは v0.3.0 向けです。

## やりたいことから探す

- 初めて使う → [インストール](user-guide/installation.md)と[初回設定](user-guide/first-setup.md)
- 今夜の就寝・起床を設定する → [スケジュール](user-guide/scheduler.md)
- 起きたあとに記録を見たり、3問に答えたりする → [睡眠ログ](user-guide/sleep-logs.md)
- VR 内から操作する → [VR Overlay](user-guide/vr-overlay.md)
- コントローラーやトラッカーの充電・電源を確認する → [デバイス管理](user-guide/device-manager.md)
- マイクや音声分析を設定する → [設定](user-guide/settings.md#audio-analysis)
- 研究への参加について知る → [Research Program](research-program/overview.md)
- 困ったとき → [FAQ](support/faq.md)と[サポート](support/support.md)
