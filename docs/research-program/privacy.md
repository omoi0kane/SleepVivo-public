# プライバシー

## 研究用のID

研究データは、SleepVivo のインストール単位のIDで管理します。研究者がインタビューを行う場合は、本人の同意を得たうえで、インタビューの内容とインストールIDを対応付けることがあります。

## 保管と削除の依頼

研究データは、長期的な変化を比較するために保管します。一律の保管期限は設けていません。

一般設定で「研究に参加する」をオフにすると、新しい研究データの送信が停止します。送信済みのデータは引き続き保管されます。削除を希望する場合は、[サポート](../support/support.md)の連絡先からご相談ください。

## 外部共有

研究結果の外部共有には別の同意が必要です。同意した場合に共有されるのは、個人を特定しにくい形に加工・集計した研究結果です。選び方は[同意と参加](consent.md)をご覧ください。
