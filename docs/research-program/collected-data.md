# 収集される情報（v0.3.0研究段階）

SleepVivo Research Programは任意参加です。参加OFFでも通常の睡眠支援とローカル結果・履歴を利用できます。

!!! note "実際に送信される項目は利用版に依存します"
    以下はv3で同意対象とする研究用の**軽量要約の範囲**です。v0.3.0開発中の新しいAudio/Interaction/Observation項目は、実際の配送実装・研究側の許可が成立するまで送信されません。旧版で既に送られている内容と混同しないでください。

## 収集対象

1. インストールIDと対応するV睡episode・セッションID、正確な開始・終了日時（記録がある場合）、制御区間長
2. HMDの静止・動き・姿勢変更候補、直接操作候補の件数・時間・率等の観測要約
3. 評価可能時間、coverage、欠測・切断・停止理由、観測元・版などの必要な来歴
4. 別途マイクを有効にした場合のspeech/snoring **candidate** 集計（原音声ではない）
5. 任意の睡眠後3問回答と、対象episodeとの対応
6. HMD機種およびアプリ・schema・model・detectorのバージョン

観測候補は生理的睡眠・覚醒、実際の寝返り、本人の発話・いびきの確定値ではありません。

## 自動送信しない情報

氏名、メールアドレス、VRChatアカウント名・ID、位置情報、原音声、文字起こし、動画、画像、スクリーンショット、生のHMDトラッキング系列、VRワールド名、同席ユーザー名、チャット内容。

## 手動の調査用ログ提出

アプリの機能によっては本人が選択した詳細ログを別途提出できます。Semantic/Raw/Observation/Systemログ等には操作記録・正確な時刻など、通常の軽量研究要約より詳細な情報が含まれる場合があります。提出時に内容を確認してください。これを研究参加ONだけで自動送信するものではありません。

## IDとインタビュー

研究データはインストール単位で扱います。研究者は本人の同意のもと、研究IDをインタビュー内容・参加者と対応付けることがあります。完全匿名とは説明しません。

## 目的・保存・停止

VR睡眠体験の把握、ソフトウェアの改善、観測結果と主観評価・インタビューの対照、長期的傾向の研究に利用します。医療診断・治療を目的としません。

長期研究のため一律の保管期限は現在設定していません。Research ProgramをOFFにすると新規送信は停止し、既存の送信済みデータは自動消去されません。過去記録の扱いは研究者へ個別相談できます。研究成果の外部共有には別の同意を用います。
