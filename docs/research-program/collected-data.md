# 収集される情報

## 研究に使う睡眠ログの要約

研究送信の対象は、参加に同意したあとに始まり、記録が確定した VR 睡眠です。[同意と参加](consent.md)で送信条件と現在の収集状況を確認できます。

- 睡眠ログの開始・終了などの正確な日時、継続時間、睡眠サポートの経過
- HMDの動き・静止・姿勢の変化、コントローラーなどの操作、発話やいびきとみられる音の集計
- 観測できた時間やデータの品質、HMDの機種、アプリ・分析モデル・同意規約のバージョン
- 起床後の3問に答えた場合は、回答と対応する睡眠ログを結びつける情報

日時は、就寝・起床の時刻の傾向や睡眠・覚醒の経過の分析に使います。音声に関して研究に使うのは、端末内で分析した集計や品質の情報です。通常の研究送信には、元の音声や文字起こし、HMDの詳細な動きの記録、映像、スクリーンショット、氏名、メールアドレス、VRChatアカウント情報は含まれません。

## 調査用ログを自分で提出する場合

アプリから調査用ログを提出する場合は、対象の日付とログの種類を自分で選びます。調査用ログには、操作や発生時刻など、研究用の要約より詳しい情報が含まれることがあります。操作手順は[サポート](../support/support.md)をご覧ください。
