# 同意と参加

参加を希望する場合は、デスクトップの「設定」から「一般設定」を開き、「研究に参加する」を選びます。「研究参加規約」で利用目的とデータの扱いを確認し、同意するかを選んでください。以前の同意で参加していた方も、v0.3.0 の研究送信には改訂後の規約への同意が必要です。

同意したうえで、研究側が利用中のインストールからの送信を許可し、研究収集を始めると送信が行われます。[収集される情報](collected-data.md)で対象を確認できます。

外部の研究・開発協力先への共有は、研究参加とは別に選べます。外部共有に同意した場合は、個人を特定しにくい形に加工・集計した研究結果が共有されます。

## 参加を停止する

「設定」から「一般設定」を開き、「研究に参加する」をオフにします。この端末からの新しい研究データの送信は停止します。端末内の睡眠ログは引き続き利用できます。送信済みのデータの削除を希望する場合は、[プライバシー](privacy.md)をご覧ください。

## 補足

v0.3.0 向けの正式な研究収集はまだ始まっていません。
