# SleepVivo Research Program 概要

SleepVivo Research Programは、VR睡眠（V睡）を日常的に記録し、体験・行動と本人の感想の変化を調べる研究です。現在は少人数の同意に基づく試験・評価段階で、運用しながら研究内容を具体化しています。

!!! note "研究参加は任意です"
    参加しなくてもSleepVivoの入眠・起床支援とローカル記録・履歴・本人フィードバックを利用できます。

## 研究内容

アプリが取得したV睡episodeの正確な日時や長さ、HMDの動き・静止・姿勢変化、直接操作の観測候補、品質・欠測、任意の3問回答等を軽量要約として利用します。マイクを別途有効にした場合は、発話様・いびき様の**候補**集計も将来対象とします。生理的睡眠・覚醒や医療診断を確定するものではありません。

新しいデータ項目が実際に送信されるかは、アプリ版と研究送信機能の対応状況によります。通常の研究自動送信には音声・文字起こし・映像・生HMDトラッキングを含めません。

## 研究者によるインタビュー

研究データはインストール単位のIDで管理します。本人の同意を得て、研究者がインタビュー対象者と研究IDを対応付けることがあります。完全匿名データとは説明しません。

## 参加・停止・保存

一般設定からResearch ProgramをONにして同意画面を確認します。既存同意版から新しいv3説明へ更新する場合は再同意が必要です。参加停止は設定からOFFにします。

研究データは長期間の比較に利用するため、現時点で一律の保存期限は設けていません。停止後、過去の送信済み記録は自動的に削除されず、研究者へ個別に相談できます。

## 外部共有

研究参加とは別の同意があれば、加工・集計した研究結果を研究・開発協力先へ共有する場合があります。

詳しくは[同意と参加](consent.md)、[収集される情報](collected-data.md)、[研究データの取扱い](privacy.md)をご確認ください。
