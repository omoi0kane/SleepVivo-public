# Research Program

SleepVivo Research Program は、VR で眠るときの体験や行動の傾向を調べ、睡眠サポートの改善に役立てる取り組みです。参加は任意です。

睡眠サポート、端末内の[睡眠ログ](../user-guide/sleep-logs.md)、起床後のアンケートは、研究に参加していなくても利用できます。音声分析のオン・オフも、研究参加とは別に設定できます。

参加条件と停止方法は[同意と参加](consent.md)、研究に使う項目は[収集される情報](collected-data.md)をご覧ください。IDや送信後のデータの扱いは[プライバシー](privacy.md)に記載しています。
