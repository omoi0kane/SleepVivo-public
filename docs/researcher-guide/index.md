# 研究者向け

SleepVivo で保存した観測記録を調べるためのガイドです。どの記録を使うか決めてから CSV に変換し、SurfCSViewer で波形やイベントを確認します。

1. [SleepVivo のデータ構造](data-structure.md)で、観測、アプリの状態や制御、本人の回答の違いを確認します。
2. [SleepVivo CSV Exporter](csv-exporter.md)で、完了した観測セッションを CSV バンドルに変換します。
3. [SurfCSViewer の使い方](surfcsviewer.md)で、バンドルから必要な波形とラベルを読み込みます。

!!! note "対象となるツール"
    このガイドでは Windows の SleepVivo CSV Exporter と、CSV バンドルの読込に対応した SurfCSViewer を使います。手元の版や入手方法が分からない場合は、[サポート](../support/support.md)をご確認ください。

Research Program への参加は任意です。このガイドで扱う端末内の記録と、研究で送信される要約は、用途と取り扱いが異なります。研究送信については[収集される情報](../research-program/collected-data.md)と[プライバシー](../research-program/privacy.md)をご覧ください。
