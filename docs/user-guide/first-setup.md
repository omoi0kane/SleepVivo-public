# 初回設定

最初の一晩は、就寝と起床の予定を入れて睡眠サポートを試してください。

## 就寝と起床の予定を入れる

1. 左メニューの「ホーム」を開きます。
2. 「就寝予定時刻」と「起床予定時刻」を入力します。「睡眠スケジュール」では、入力した時刻が毎日の固定時刻に反映されます。「次の予定を編集」と表示されている場合は、入力してから「確定」を押します。
3. 上部の「次の就寝予定」と「次の起床予定」で日付と時刻を確認します。

![固定時刻を使うときのホーム画面の睡眠スケジュール](../assets/img/v030-home-fixed-times.png)

起床の支援だけ使う場合は、就寝予定を空欄にします。日によって予定を変えるときは、[スケジュール](scheduler.md)でカレンダーを使えます。

## 起きたあとに確認する

「ホーム」の「睡眠ログを見る」か、左メニューの「睡眠ログ」から今回の記録を確認できます。起床後のアンケートに答えると、その日の寝つきや満足度も残せます。[睡眠ログの見方](sleep-logs.md)をご覧ください。

明るさや音量が合わないときは、次に使う前に[睡眠サポート](sleep-support.md)を調整してください。
