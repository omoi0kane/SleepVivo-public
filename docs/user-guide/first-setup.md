# 初回設定

初めの一晩は、就寝と起床の予定を入れて睡眠サポートを試してください。

## 次の予定を入れる

1. デスクトップの「概要」を開き、「次の予定を編集」を押します。
2. 「就寝予定時刻」と「起床予定時刻」を入力し、「確定」を押します。
3. 「次の就寝予定」と「次の起床予定」に表示された日付と時刻を確認します。

起床の支援だけ使いたいときは、起床予定だけを入力できます。毎日同じ時刻や曜日ごとの予定を設定するには、[スケジュール](scheduler.md)を開きます。

## 起きたあとに確認する

「概要」から「睡眠ログを見る」を押すと、今回の記録を確認できます。起床後のアンケートに答えると、その日の寝つきや満足度も残せます。[睡眠ログの使い方](sleep-logs.md)をご覧ください。

明るさや音量が合わないときは、次に使う前に[睡眠サポート](sleep-support.md)を調整してください。
